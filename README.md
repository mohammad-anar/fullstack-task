# Doctor Tracker - Secure Administrative Web Application

Doctor Tracker is a modern fullstack administrative application for managing doctors, patients, and healthcare analytics.

## Tech Stack
- **Framework**: Next.js (App Router with TypeScript)
- **State & Data Fetching**: Redux Toolkit & RTK Query
- **Styling & Components**: Shadcn UI & Tailwind CSS
- **Database**: MongoDB with Mongoose
- **Visualization**: Recharts
